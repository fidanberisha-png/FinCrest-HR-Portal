# FinCrest HR Portal - Implementation Guide

## Tasks Summary

This guide covers the implementation of 4 major features for the HR portal system based on Kosovo Labour Law (Law No. 03/L-212).

### Task 1: Resend Domain Configuration ✅ (Already Configured)
The system is already configured to use Resend API (see lib/mailer.js). Ensure:
- RESEND_API_KEY environment variable is set
- Domain verification completed in Resend dashboard
- DNS records (SPF, DKIM, CNAME) configured

### Task 2: 1-Day Minimum Leave Request Restriction
### Task 3: Admin/Approver Dashboards
### Task 4: Employee Start Date & Leave Eligibility (6-Month Rule)
